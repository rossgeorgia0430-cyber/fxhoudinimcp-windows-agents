    diagnostics ¶

    MCP tools for read-only diagnostics: geometry chains and diffs, mesh topology and UVs, ray casts, name-keyed motion and RBD statistics, and FBX / HIP file inspection.

    inspect_fbx async ¶

    inspect_fbx(
    ctx: Context,
    file_path: str,
    compare_sop_path: str | None = None,
    name_attrib: str = "name",
    frames: list[float] | None = None,
    max_listed: int = 20,
    timeout: float | None = None,
) -> dict

    Re-import an exported FBX and prove what it contains.

    Imports into a temporary subnet (deleted afterwards; units converted to meters) and reports object types, mesh nodes, closed polygons, other primitives (curves), the transform key range, material names, mesh nodes that stay static while the file is animated, and curve-only nodes (open polylines the FBX ROP split into their own node, which then take the animation from the mesh). With compare_sop_path pointing at the unpacked source pieces, each mesh node's world bbox centre is compared with the same-named piece (non [A-Za-z0-9_] characters become "_", as the importer does) at frames (default: first, middle, and last key).

    Unpacked SOP with one name per piece.

    Comparison frames.

    		 None

    inspect_hip_file async ¶

    inspect_hip_file(
    ctx: Context,
    hip_path: str,
    root_path: str = "/obj",
    max_depth: int = 2,
    max_nodes: int = 100,
    timeout: float | None = None,

    Read another HIP file's network without opening it in the live session.

    A separate hython loads the file and lists, below root_path, every node's type, inputs, flags, and only its non-default parameters (values, expressions, key counts; long strings such as VEX snippets are kept up to 4000 characters). Locked asset internals are skipped except editable sections, e.g. a solver's forces subnet. Narrow root_path to the node of interest and raise max_depth to see inside it.

    mesh_topology_report async ¶

    mesh_topology_report(
    ctx: Context,
    node_path: str,
    piece_attrib: str | None = None,
    max_pieces: int = 20,
) -> dict

    Prove whether a mesh is closed and connected before fracturing, booleans, or export.

    Reports closed polygons, open curves (open polylines), non-polygon prims, connected components, boundary (open) and non-manifold edges, surface area, and for closed shells the enclosed volume and whether normals face outward. Faces connect only through shared points, so unfused UV-seam points show up as open edges. With piece_attrib (e.g. "name") every piece is measured separately: pieces made of several parts, open pieces, or pieces carrying open curves are listed, plus the closed-volume distribution.

    Parameters:

    Name Type Description Default
    node_path ¶
    		 str

    SOP node path.

    		 required
    piece_attrib ¶
    		 str | None

    Optional primitive attribute that identifies pieces.

    		 None
    max_pieces ¶
    		 int

    Max problem pieces listed.

    		 20

    ray_intersect async ¶

    ray_intersect(
    ctx: Context,
    node_path: str,
    direction: list[float] | None = None,
    origins: list[list[float]] | None = None,
    grid_center: list[float] | None = None,
    grid_size: float | None = None,
    grid_resolution: int = 10,
    max_distance: float | None = None,
    label_attrib: str | None = None,
    max_results: int = 200,

    Cast rays at SOP geometry: ground heights, clearances, and coverage holes.

    Pass explicit origins, or grid_center + grid_size to cast a grid_resolution x grid_resolution grid of rays from a square facing direction (the way to find where a collision floor has gaps). Each ray reports hit position, normal, distance, and primitive; label_attrib adds the hit primitive's attribute value (e.g. "name") and per-label hit counts. Positions are in the SOP's own space.

    rbd_motion_stats async ¶

    rbd_motion_stats(
    ctx: Context,
    node_path: str,
    start_frame: float,
    end_frame: float,
    sample_frames: list[float] | None = None,
    name_attrib: str = "name",
    center: list[float] | None = None,
    up_axis: str = "y",
    moving_speed: float = 0.3,
    rebound_speed: float = 0.5,
    reset_node_path: str | None = None,
    top_n: int = 5,
    timeout: float | None = None,
) -> dict

    Step a rigid-body result frame by frame and measure how it actually moves.

    Reads named points (e.g. the RBD Bullet Solver's simulation points, or any packed-piece output) every frame from start to end and reports, at sample frames: speed p50/max, moving count, horizontal spread from a centre (p50/p90/max), height min/max, and max spin (w). Over the whole range: the settle frame, the lowest point reached (floor penetration), per-piece peak upward speed after start (rebound strength), and the farthest pieces. Velocity comes from v when present, otherwise from P differences. These are the numbers to compare when tuning bounce, drag, gravity, or impulses.

    Name Type Description Default
    node_path ¶
    		 str

    SOP node whose points are the pieces.

    		 required
    start_frame ¶
    		 float

    First frame (the solver start or handoff frame).

    		 required
    end_frame ¶
    		 float

    Last frame.

    		 required
    sample_frames ¶
    		 list[float] | None

    Frames reported in detail. Omitted → 8 spread frames.

    		 None
    name_attrib ¶
    		 str

    Point attribute naming each piece.

    		 'name'
    center ¶
    		 list[float] | None

    Spread origin. Omitted → centroid at start_frame.

    		 None
    up_axis ¶
    		 str

    "x", "y", or "z".

    		 'y'
    moving_speed ¶
    		 float

    Speed above which a piece counts as moving.

    		 0.3
    rebound_speed ¶
    		 float

    Upward speed above which a piece counts as rebounding.

    		 0.5
    reset_node_path ¶
    		 str | None

    Solver SOP or DOP network to reset first, so the whole range re-simulates and the timing covers it.

    		 None
    top_n ¶
    		 int

    Farthest pieces listed.

    		 5
    timeout ¶
    		 float | None

    Bridge timeout in seconds for long simulations.

    		 None

    track_named_elements async ¶

    track_named_elements(
    ctx: Context,
    node_path: str,
    frames: list[float],
    names: list[str] | None = None,
    name_attrib: str = "name",
    attribs: list[str] | None = None,
    element_class: str = "point",
    include_bounds: bool = False,
    max_names: int = 50,
    timeout: float | None = None,

    Follow named points or primitives across frames, matched by name, not index.

    For each frame reads numeric attributes of every element with a given name (KineFX joints, packed RBD pieces, sim points) and optionally the bounds of all elements sharing the name (e.g. the prims of one unpacked piece). Use it to compare motion against a reference, derive velocities, or record per-piece centres before an export round-trip. Frames cook in the order given, so pass them ascending for simulations.

    		 required

    Frames to sample.

    		 required
    names ¶

    Names to follow. Omitted → the first max_names names, sorted.

    		 None
    name_attrib ¶
    		 str

    String or integer attribute holding the name.

    		 'name'
    attribs ¶
    		 list[str] | None

    Numeric attributes to read (default ["P"]).

    		 None
    element_class ¶
    		 str

    "point" or "prim".

    		 'point'
    include_bounds ¶
    		 bool

    Add min/max/center of all elements with the name.

    		 False
    max_names ¶

    Cap when names is omitted.

    		 50

    uv_quality_report async ¶

    uv_quality_report(
    ctx: Context,
    node_path: str,
    uv_attrib: str = "uv",
    groups: list[str] | None = None,
) -> dict

    Check UVs per primitive group: collapsed, flipped, and texel-scale spread.

    For every closed polygon compares UV area against 3D area. Reports polygons whose UVs collapsed to a line or point (degenerate_uv), polygons wound against the majority (flipped_uv; mirrored islands count), texel scale (UV units per scene unit) p1/p50/p99 and their spread, and the UV bounds. Use it on fracture interiors or any generated UVs before export.

    Parameters:

    Name Type Description Default
    node_path ¶
    		 str

    SOP node path.

    		 required
    uv_attrib ¶
    		 str

    Vertex or point UV attribute (default "uv").

    		 'uv'
    groups ¶
    		 list[str] | None

    Primitive group patterns to report separately, e.g. ["inside", "* ^inside"]. Omitted → all primitives.

    		 None
